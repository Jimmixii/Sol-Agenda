# Sol Agenda

Personal Warframe build, Armory, weekly-progress, and farming tracker.

## GitHub Pages deployment

1. Upload `index.html`, `sol-sun.jpg`, and `.nojekyll` to the root of the repository.
2. In GitHub, open **Settings → Pages**.
3. Set the source to **Deploy from a branch**, then select `main` and `/ (root)`.
4. Wait for the Pages workflow to finish, then hard-refresh the site with `Ctrl + Shift + R`.

## Saving personal data

Tracker changes are stored locally in the browser for the current site address. Use **Download backup** on the Overview page before clearing browser data, changing domains, or moving to another device. Use **Restore backup** on the new device or address.

## Current Armory behavior

- Select any mod name on a weapon build to edit it.
- Click or tap elsewhere to save the text.
- Mod names and polarities save separately for every weapon configuration.
- Uploaded frame portraits and their positioning remain browser-local and are included in tracker backups.
